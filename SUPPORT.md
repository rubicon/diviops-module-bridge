# Support

## Before opening an issue

Check that DiviOps Agent is installed and active. This plugin declares it as a dependency and does nothing without it.

Confirm the module you are targeting is actually registered. A module whose plugin is deactivated will not resolve, and the schema response says which source answered so you can tell the difference.

## Where to ask

- **Bugs and feature requests for this plugin:** [open an issue](https://github.com/rubicon/diviops-module-bridge/issues).
- **Questions about DiviOps itself:** the [DiviOps project](https://github.com/oaris-dev/diviops). Please do not open DiviOps questions here.
- **DiviFlash, Divi Background Plus, or Divi Event Calendar Module questions:** their respective vendors.
- **Security issues:** see [SECURITY.md](SECURITY.md). Do not open a public issue.

## What helps

WordPress, PHP, Divi, and DiviOps Agent versions. The block name you were targeting and how you targeted it. The full DiviOps error envelope if you got one.

## Scope

This is a bridge for a specific gap in DiviOps, maintained in spare time and intended to be made obsolete by an upstream fix. It is not a general Divi automation tool, and requests to grow it in that direction will be declined.
